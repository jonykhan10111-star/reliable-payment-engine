## Reliable Payment Engine
A professional JavaScript payment-processing simulation focused on reliable error handling and automated testing.

## 🗒️ Features
- ES Modules
- `.mjs`
- Strict Mode
- Custom Error Types
- Assertions
- Error Propagation 
- Selective Catching
- Retry Logic
- `try...catch...finally`
- Automated Testing
- Payment Gateway Simulation
- Processing State Cleanup
- Transaction ID Generation

## Run

```bash
node app.mjs
node tests.mjs
```
